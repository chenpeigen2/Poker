# 《读局》Read the Room

> 单挑无限注德州扑克，对手是**可以被读、被针对**的 AI。
> 你的目标不是打赢一手牌，是归纳出对面那个人的破绽，然后施压。

## 快速开始

```bash
pnpm install
pnpm dev        # 打开本地 Vite 开发服务器
pnpm verify     # no-any 检查 + 类型检查 + 单测 + 生产构建
```

零网络请求即可完整可玩：LLM 表达层在 v1 默认降级为本地模板。

## 项目结构

| 包 | 职责 | 依赖 |
|---|---|---|
| `packages/domain` | 唯一契约：类型、常量、纯函数 | 无 |
| `packages/engine` | HU NLHE 规则、牌力评估、确定性回放 | `domain` |
| `packages/ai` | 人格化对手、结构化意图、破绽档案 | `engine`, `domain` |
| `apps/web` | R3F 3D 牌桌 + DOM 档案/复盘面板 | 全部 |

依赖严格单向：`web → ai → engine → domain`。

## 核心循环

```
提出假设 → 主动试探（花筹码买信息）→ 观察反应 → 判定反馈 → 修正画像 → 针对性施压
```

## 现在能玩到什么

- **3D 牌桌**：程序化毡布/木纹/牌面贴图、发牌与推池动画、摊牌赢家高亮、对手思考节奏、轮次指示灯、相机视差、WebAudio 程序化音效。零外部素材。
- **4 个可归纳的对手**：紧弱账房、疯鲨、跟注站、读局者。破绽由参数直接驱动，可被观察、被针对。
- **完整读人闭环**：7 类假设 → 试探（含 check-call）→ 信息泄漏条 / 思考时长 / 行为时间轴 → 明确「成立/不成立」判定 + 逐手证据链 → 针对性施压高光。
- **复盘联动**：点「在 3D 牌桌上重演」，同一张桌子逐帧回放历史手牌；`← →` 逐步，`Esc` 返回实时。
- **键盘操作**：`F` 弃牌 / `K` 过牌 / `C` 跟注 / `B` 下注 / `R` 加注 / `A` 全下 / `P` 试探。
- **持久化**：每个对手独立档案、会话战绩、牌局记录全部存 `localStorage`，刷新不丢。

## 工程规范

- TypeScript `strict`，**任何位置禁止 `any`**（由 `scripts/check-no-any.mjs` 做 AST 检查）。
- `engine` / `ai` 核心逻辑为纯函数，随机性全部由 `seed` 派生，保证每一手牌可逐字段回放。
- 先写测试再写实现：牌力评估穷举对照、底池守恒、回放确定性、下注边界。
